# Create a Web Blog using WordPress

1. Install WordPress locally (for example, with LocalWP) or use a WordPress hosting account.
2. Sign in to the WordPress Dashboard and choose **Posts → Add New**.
3. Add a post title (demonstrates the page/post title).
4. Add a Paragraph block and an Image block.
5. Add an anchor (link): select text, click the link icon, and enter `https://example.com`.
6. Add a Custom HTML block to demonstrate HTML title and anchor tags:

```html
<h2 title="About this blog">About This Blog</h2>
<p>Visit <a href="https://wordpress.org" title="WordPress website">WordPress</a>.</p>
```

7. Preview, publish, and verify the link opens correctly. The `title` attribute provides advisory text; the visible heading is the page content.
